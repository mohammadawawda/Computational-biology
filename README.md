# Computational Biology

Computational biology projects in Python.

* [cfdna_hackathon](cfdna_hackathon) hackathon project. Checking for fetal trisomy 21 from shallow cfDNA sequencing.
* [segmentation](segmentation) splitting a noisy signal into segments with dynamic programming, plus a runtime analysis.
* [hmm_cpg_islands](hmm_cpg_islands) a two state HMM trained with EM, and an HMM that finds CpG islands in DNA.
* [phylogenetics](phylogenetics) building phylogenetic trees and rebuilding ancestor sequences.
* [savana_presentation](savana_presentation) my presentation of the SAVANA paper (Nature Methods, 2025).

The data files are not included.
